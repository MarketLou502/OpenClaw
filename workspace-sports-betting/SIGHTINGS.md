# SIGHTINGS.md - Daily EV Sightings Log

Entries here are raw bets sourced from the CrazyNinjaOdds daily bets file before filtering. An entry is written when it passes the basic EV threshold but before quota and camouflage rules are applied. Promoted entries move to BET_QUEUE.md.

**Entry format:**

```
## [YYYY-MM-DD HH:MM] | [Sport] | [Game] | [Market]
- Source: CrazyNinjaOdds | Book: [Book]
- Pick: [Side/Team] [Line]
- Odds: [American]
- EV: +X.X% (pre-calculated)
- Tier: SHARP_MAIN | SHARP_PROP | CAMOUFLAGE | DISCARD
- Discard reason (if applicable): above +14% / prop above +8% / below -1% / quota full
- Status: PENDING | PROMOTED | DISCARDED | EXPIRED
```
