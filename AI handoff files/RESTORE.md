# Disaster Recovery: Restoring OpenClaw on a New Machine

This repo backs up OpenClaw's source, config structure, and agent
documentation — not credentials or conversation history. Those are
excluded on purpose (see the root `.gitignore`) and are not recoverable
from git. This doc is the checklist to get a working instance back up.

## What you get for free from this repo
- All agent workspace docs (SOUL/AGENTS/MEMORY.md, etc.)
- `openclaw.sanitized.json` — a structurally-current copy of the real
  config, regenerated by `scripts/sanitize-openclaw-config.py`, with
  secret values replaced by `<REDACTED: ...>` placeholders
- `services/dashboard-api`, `services/ha-voice-adapter`,
  `services/shared-routine-router` source code
- `automation/*.plist` launchd definitions

## What you must redo manually
1. Reinstall Node/npm and the `openclaw` package itself (not in this repo).
2. Copy `AI handoff files/openclaw.sanitized.json` to `openclaw.json` at
   the repo root.
3. Replace every `<REDACTED: ...>` placeholder:
   - `gateway.auth.token` — any new random string works (gateway mode is
     `none`, so this isn't actively enforced locally, but keep it set).
4. Recreate `.env` with fresh values for `OPENROUTER_API_KEY` and
   `DISCORD_SPORTS_BETTING_TOKEN` (OpenRouter dashboard / Discord
   Developer Portal — regenerate if the old ones aren't saved elsewhere).
5. Re-provision the Anthropic API key through OpenClaw's normal auth
   setup step (this populates `agents/*/agent/auth-profiles.json`, which
   is never committed to git).
6. Re-run Google Calendar OAuth to recreate `credentials/google-calendar.json`.
7. Devices/identity (`devices/`, `identity/`) regenerate automatically
   when you pair a new device — nothing to restore there.
8. `services/whisper-mlx`, `services/mlx-lm`, `services/home-assistant`
   were deliberately left out of git (reinstallable Docker
   appliance/model downloads, not original source) — reinstall those
   fresh if you still want the voice pipeline.

## What is permanently lost (not backed up here, by design)
- All agent conversation memory/session history (`agents/*/sessions`,
  `memory/*.sqlite`)
- Health, finance, and sports-betting tracked data (all `*.sqlite`/`*.db`)
- iMessage cache and inbound photos (`imessage/`, `media/`)

Every agent starts with a blank memory on a restored instance. The
config/architecture/code side is fully recoverable; the data/state side
is not — back that up separately (e.g. an encrypted archive of the
SQLite files) if it matters to you.

## Keeping this backup current
Run `python3 scripts/sanitize-openclaw-config.py` after any meaningful
change to `openclaw.json`, then commit the updated
`openclaw.sanitized.json` before pushing. It's a plain script, not part
of the running app — safe to run any time.
